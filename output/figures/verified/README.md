# 검증 완료 추가 그래프

아래 3개 PNG는 기존 핵심 그래프 5종과 분석 내용이 겹치지 않도록 재제작한 보고서 삽입 후보이다.

1. `06_가입자100명당_전체연금수급자.png`
   - 공식 홈페이지의 2021~2025년 가입자·전체 연금수급자 정확값 사용
   - `전체 연금수급자÷가입자×100`을 팀 계산
2. `07_2025년_교원퇴직사유_구성.png`
   - 공공데이터포털 ID 15131720 원본 103행의 학교급별 수치를 퇴직사유별로 합산
   - 파일 내부 총계 14,193명과 다른 공식 파일의 14,789명 차이를 그래프 하단에 명시
3. `08_연령대별_퇴직연금수급자_분포.png`
   - 공공데이터포털 ID 15045812 원본 42행의 교원·사무직원 남녀 수급자 수를 합산
   - 원자료 `n미만`을 상한 미만으로 해석해 `60미만` 행을 60세 미만에 포함

재현 코드: `scripts/create_verified_supplementary_figures.py`

검증값: `output/evidence/추가그래프_검증값_20260831.json`

원자료와 계산 방식이 그래프 하단에 표시돼 있다. `output/figures/team_candidates/`에 있는 이전 이미지를 최종본으로 사용하지 않는다.
