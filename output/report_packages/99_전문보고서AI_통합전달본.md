# 전문 보고서 제작 AI 통합 전달본

- 작성일: 2026-08-31
- 상태: 최종 통합 전달본 (00·01~08의 9개 장별 패키지 완성 후 취합)
- 목적: 전문 보고서 제작 AI가 이 문서 하나를 진입점으로 삼아 나머지 9개 장별 패키지, 검증 그래프, 정제 데이터, 재현 코드, 재현 검증 산출물을 어떤 순서·어떤 규칙으로 읽고 조판할지 파악하도록 한다.
- 이 문서는 **내용 재생성이 아니라 경로·규칙·조판 계약의 통합**이다. 개별 장의 본문 원고·팩트시트·시각자료 삽입표는 각 장 패키지 원본을 그대로 사용한다.
- 이 문서에서 새로운 수치·해석·제안을 만들지 않는다. 모든 인용은 앞서 완성된 9개 장별 패키지 및 `docs/15·16·17·18`의 확정 내용에서만 가져온다.
- 최종 산출물은 별도의 전문 보고서 제작 AI가 조판한다. Codex는 사용자 재지시 전까지 DOCX·PDF·PPT·앱·대시보드를 직접 생성하지 않는다.

## 1. 이 문서의 사용법

### 1.1 문서의 성격

이 통합 전달본은 다음 두 가지를 동시에 제공한다.

1. **네비게이션**: 최종 보고서를 조립하기 위해 어떤 파일을 어떤 순서로 읽어야 하는지.
2. **전역 규칙**: 문서마다 반복 서술된 사실/해석/가설/제안 구분, 금지 주장, 절대 혼용 금지 수치, 조판 스타일을 한곳에 집약해 조판 AI가 참조할 단일 진입점.

이 문서는 개별 장의 본문 원고를 다시 쓰지 않는다. 조판 AI는 이 문서를 **인덱스**로 사용하고, 실제 원고는 해당 장 패키지 파일에서 읽어 그대로 조판한다.

### 1.2 조판 AI가 반드시 지켜야 할 다섯 가지

1. **원고 발명 금지**: 장별 패키지의 §4 본문 원고를 축약·확장·재작성하지 않는다. 사실·해석·가설·제안의 성격을 바꾸지 않는다.
2. **수치 발명 금지**: 이 문서 §8 전역 팩트 인벤토리와 각 장 팩트시트에 없는 새 수치를 만들지 않는다.
3. **금지 주장 준수**: 이 문서 §9 전역 금지 주장을 어떤 장에서도 위반하지 않는다.
4. **혼용 금지 수치 구분**: 이 문서 §8.2 절대 혼용 금지 수치를 하나로 합치거나 임의로 대체하지 않는다.
5. **범위 표기 유지**: `186개 전수검토`는 항상 메타데이터 범위, `15개 심층검사`는 원본값 범위로 표기한다. 두 범위를 섞지 않는다.

### 1.3 최종 산출물 조판 순서

```
[표지] → [제출문 또는 팀·과제 정보] → [요약문] → [목차] → [Ⅰ. 연구 개요] → [Ⅱ. 공공데이터 활용 및 검증방법] → [Ⅲ. 퇴직자·수급자 변화 분석] → [Ⅳ. 현행 디지털 고객서비스 공개데이터 분석] → [Ⅴ. 분석 공백 및 공공데이터 품질진단] → [Ⅵ. 디지털 고객서비스 공공데이터 고도화 방안] → [Ⅶ. 공단 활용방안·실행 로드맵·성과지표] → [Ⅷ. 결론] → [부록 A~G]
```

각 위치에서 사용할 패키지 파일과 시각자료는 §2·§4·§5·§6에서 지정한다.

## 3. 제목·목차·전체 구조

### 3.1 제목과 부제 (확정)

**제목**: 퇴직자·수급자 변화 분석을 통한 사학연금 디지털 고객서비스 공공데이터 고도화 방안

**부제**: 공단 공개데이터 186개 전수검토와 신규 개방 설계를 중심으로

**한 문장 주장**: 사학연금 공개데이터는 퇴직자·수급자의 장기 변화와 일부 상담·온라인 접수 현황을 파악하는 데 유용하지만, 수치 정의·기준일·연결 변수의 불일치로 연령대별 디지털 이용 편의성과 채널 전환을 직접 측정하기 어렵다. 따라서 기존 데이터의 품질 개선과 `연령대×채널×인증×업무완료` 통계의 단계적 개방을 병행해야 한다.
