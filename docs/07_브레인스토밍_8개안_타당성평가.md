- 고정 과제: `공공데이터 활용 퇴직자 수 변화와 수급자의 증감 분석 및 특징 도출`

## 결론

이 프로젝트는 `주제를 다 정하고 데이터를 끼워 맞추기`와 `질문 없이 데이터부터 보기` 중 하나를 고르는 일이 아니다.

1. 지금은 고정 과제 안에서 반드시 답할 **핵심 질문**을 선정한다.
2. 공개데이터의 기간·컬럼·집계 단위를 점검한 뒤 **가능한 세부 분석**을 확정한다.
3. 탐색 분석에서 새 특징이 나오면 `탐색 발견`으로 추가하고 다른 기간·집단에서 재검증한다.

즉, **큰 방향은 연역적으로 고정하고, 특징은 귀납적으로 찾은 뒤 다시 검증하는 혼합형**이 맞다.

## 8개 후보 판정표

| 번호 | 판정 | 이유와 수정 방향 |
|---|---|---|
| 1. 연도별 퇴직자 추이(교원 vs 사무직원) | **핵심** | 과제와 직접 일치하고 공개데이터가 있다. 다만 직종 비중만으로 `향후 부담 주체 비중`을 결론내면 안 된다. `어느 직종에서 퇴직 유입 압력이 커지는가`로 바꾼다. |
| 2. 학교급별 퇴직자 분포 변화 | **핵심** | 과제와 직접 일치한다. 인원이 많다고 `재정 리스크가 크다`고 할 수는 없다. 가능하면 재직자 1,000명당 퇴직률로 보정해 `퇴직 집중 학교급`을 찾는다. |
| 3. 개인·법인·국가 부담률 추이 | **배경 자료** | 부담률은 법·제도가 결정하는 값이라 주요 데이터 발견보다 제도 변화표에 가깝다. 교원과 사무직원의 부담 구조도 다르다. 연구 배경에는 유용하지만 핵심 분석은 아니다. |
| 4. 학교급별 법인부담금 vs 국가부담금 | **현 로직 제외** | `학교급별 퇴직자 비중 × 전체 부담률`은 실제 부담금 근사치가 아니다. 부담금은 기준소득월액·재직자·직종·법정 규칙에 좌우되므로 필요한 원자료와 산식을 확보하기 전에는 하지 않는다. |
| 5. 가입기간별 퇴직자 분포와 소득 상관 | **가명데이터 확인 후 조건부** | 같은 개인에 가입기간·소득·퇴직 여부/연도가 있어야 한다. 기준소득월액 재직자 자료만 오면 `퇴직자 소득 구조`를 추정할 수 없다. 가능해도 원인·미래예측이 아니라 `연관성`으로 쓴다. |
| 6. 향후 N년 부담금 전망 | **현재 제외, 예측 대상 수정** | 미래 재직자, 기준소득월액, 직종 구성, 법정 부담률 가정이 모두 필요하고 고정 과제와도 거리가 있다. 예측을 한다면 `1~3년 퇴직자 또는 퇴직연금수급자 시나리오`로 바꾼다. |
| 7. 직종 구성비에 따른 법인 부담 민감도 | **후순위 조건부** | 법정 산식·직종별 소득·재직자 수가 있으면 가능하다. 그러나 고정 과제의 핵심 결론이 아니므로 기본 분석 완성 후 부록 후보로 둔다. |
| 8. 지역별 퇴직자·수급자 지도 | **관측값만 조건부** | 지역별 퇴직자 공개자료는 있으나 확인된 파일은 17개 지역의 한 시점 집계다. 수급자 지역이 없으면 임의 보정하지 않는다. 지도 자체가 깊은 분석은 아니며 지역으로 특정 법인의 부담도 추론할 수 없다. |

## 이 목록에서 빠진 필수 분석

팀원 안은 퇴직자와 부담금에 치우쳐 고정 과제의 두 번째 축인 **수급자 증감 분석**이 부족하다.

1. **연도별 퇴직연금수급자 수와 증가율**: 수급자 재고(stock)가 언제 빠르게 늘었는지 찾는다.
2. **수급자 순증 분해**: `전년 수급자 + 신규 수급개시 - 수급종료 ± 조정`으로 증가 원인을 나눈다. 신규·종료 통계는 정보공개청구 결과에 따라 확정한다.
3. **퇴직자→수급자 관계와 시차**: 같은 해 값을 바로 나누지 말고 지급개시연령·연금선택·대기기간을 고려한다.
4. **특징→공단 행동**: 퇴직·수급 집중 집단, 업무량 증가 시기, 필요한 상담·안내, 추가 개방 데이터와 KPI를 제안한다.

## 권장 최종 구성

### 필수 핵심

1. 직종별 퇴직자 장기 추이
2. 학교급별 퇴직 분포·율 변화
3. 퇴직연금수급자 장기 추이와 순증 분해
4. 퇴직자와 수급자의 시차 관계·특징
5. 공단 활용안·성과지표·추가 데이터 개방안

### 데이터가 오면 추가

- 개인 단위 가입기간·기준소득월액 특징
- 실제 관측된 지역별 퇴직자 지도
- 1~3년 퇴직자·수급자 시나리오

### 제외·보류

- 퇴직자 비중에 전체 부담률을 곱한 학교급별 부담금 근사
- 입력변수와 제도 가정이 없는 부담금 예측
- 관측되지 않은 수급자 지역을 임의 보정한 지도

## 팀 선택 절차

1. 후보를 `고정 주제 적합성 / 필요 컬럼 보유 / 방법 타당성 / 공단 활용성 / 3인 팀 수행 가능성`으로 평가한다.
2. 공개 CSV를 받아 1~2일 동안 기간·컬럼·결측·집계 단위를 점검한다.
3. 필수 핵심 4~5개만 분석 계획으로 잠그고 나머지는 조건부 백로그로 둔다.
4. 탐색 중 새 특징이 보이면 기록하고 다른 기간·집단에서 다시 확인한다.
5. 결과가 예쁘게 나온 분석만 고르지 말고 비유의·실패·한계도 보고서에 남긴다.

## 팀 단톡방에 보낼 5줄

> 우리 대주제는 이미 `퇴직자 변화+수급자 증감+특징 도출`로 확정됐고, 1~8번은 세부 분석 후보야.
> 일단 1·2번과 수급자 증감 분석을 핵심 질문으로 잡고, CSV 컬럼·기간을 확인한 후 세부 모델을 확정하자.
> 4번의 `퇴직자 비중×전체 부담률`은 실제 학교급별 부담금을 추정할 수 없으므로 제외하는 게 맞아.
> 5번은 가명데이터 컬럼 확인 후, 8번은 실제 지역 관측값이 있을 때만 하자.
> 예측을 하려면 부담금보다 대주제에 맞는 1~3년 퇴직자·퇴직연금수급자 시나리오로 바꾸자.
