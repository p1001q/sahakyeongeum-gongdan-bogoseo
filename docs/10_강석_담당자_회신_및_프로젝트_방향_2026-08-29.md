# 강석 담당자 회신 및 프로젝트 방향

- 수신일: 2026-08-29
- 발신자: 강석 / 사립학교교직원연금공단 AI융합보안팀
- 문서 성격: 담당자 회신 원문 보존 및 제출 직전 방향 전환 근거
- 출처: 박수연 사용자가 제공한 이메일 본문

## 가장 중요한 결론

> 이번 제출은 가명데이터를 기다리지 않는다. 이미 개방된 공공데이터로 수급자·연금액 추이를 분석하고, 분석하지 못한 고령층의 디지털 이용 문제를 해결하기 위해 신규 공공데이터 개방안을 제안한다.

## 1. 회신에서 확인된 사실

| 구분 | 확인 내용 |
|---|---|
| 가명데이터 | 추출·반출·적정성 검토에 아무리 빨라도 영업일 3일이 필요하며, 현재 시점에는 제공 요청이 받아들여지지 않을 가능성이 매우 높다. |
| 이번 제출의 데이터 | 공단이 이미 개방한 공공데이터를 사용해 분석 보고서를 작성하는 방향이 권고됐다. |
| 공단의 현황 | 담당자 설명에 따르면 공단은 공공데이터 186개를 개방 중이며, 현재 개방 자료는 모두 통계자료다. |
| 평가 | 강석 담당자가 직접 심사하지 않고 내부 혁신보드 위원이 심사한다. 학생 프로젝트라는 점은 심사 측에 여러 차례 설명됐다. |
| 공정성 | 제출 팀 간 순위를 나누는 심사이므로 공정하고 투명하게 운영된다고 안내됐다. |

## 2. 담당자가 제안한 연구 전개

| 단계 | 내용 |
|---|---|
| 1 | 현재 개방된 자료에서 연도별 연금수급자 증가 추이와 연금액 추이를 분석한다. |
| 2 | 고령화와 사학연금 수급자 증가의 관련성을 공식 통계와 함께 해석한다. |
| 3 | 고령 수급자의 홈페이지 접속·인증 편의성을 분석하려 했으나 필요한 공공데이터가 개방돼 있지 않다는 한계를 밝힌다. |
| 4 | 어떤 통계를 새로 개방해야 하는지와 그 이유를 구체적으로 제안한다. |
| 5 | 제안 데이터가 고령층 편의 개선과 공단 서비스 개선에 어떻게 쓰일 수 있는지 설명한다. |

## 4. 우리 팀의 즉시 작업 해석

아래 내용은 회신 원문이 아니라, 마감 상황을 반영한 현재 작업 판단이다.

| 구분 | 현재 판단 |
|---|---|
| 중심 산출물 | 시간상 PPT보다 근거와 한계를 설명하기 쉬운 분석 보고서를 우선 제작한다. |
| 연구 구조 | `기존 공공데이터 분석 + 데이터 공백 확인 + 신규 공공데이터 개방 제안`의 결합형으로 전환한다. |
| 기존 선택 과제와의 연결 | 연도별 퇴직자·수급자 증감 분석은 가능한 범위에서 유지하고, 결론을 수급자 증가에 대응하는 디지털 서비스 데이터 개방 제안으로 연결한다. |
| 가명데이터 | 이번 제출의 전제에서 제외한다. 도착 여부를 기다리지 않는다. |
| 주의 | 고령화가 수급자 증가를 ‘일으켰다’고 단정하지 않고, 각각의 공식 통계 추세가 함께 나타나는지를 비교한다. |
| 마감 | 사용자 파악상 2026-08-31 23:59. 공식 공지와 다를 경우 공식 공지를 우선한다. |
