# 퇴직자 변화와 수급자 증감 연구설계 및 데이터 확보안

> **문서 상태 — 과거 참고:** 초기 연구설계와 신청 검토 이력이다. 가명데이터·예측 계획은 현재 범위가 아니며, 최신 구조는 `16_최종_보고서_목차_및_논리구조_픽스_2026-08-31.md`를 따른다.

- 작성일: 2026-08-10
- 상태: 2026-08-10 신청 절차 정정 반영. 실제 제공 컬럼과 최종 마감일 확인 후 확정

## 1. 우리가 하려는 일을 쉬운 말로 설명하면

해마다 새로 퇴직하는 사람은 미래의 연금수급자 후보가 된다. 그러나 모든 퇴직자가 바로 연금을 받는 것은 아니고, 지급개시연령·재직기간·급여 선택에 따라 수급 시작 시점이 다르다. 한편 기존 수급자가 사망 등으로 수급을 종료하기도 한다.

이 연구는 다음 연결고리를 숫자로 설명한다.

`재직자 구조 -> 퇴직 발생 -> 연금/일시금 선택 -> 연금 지급 시작 -> 수급 지속·종료 -> 전체 수급자 증감`

최종적으로는 공단이 “어느 집단에서 퇴직과 신규 수급이 늘어나는지, 언제 업무·재정 부담이 커질지, 어떤 정보를 더 관리·개방해야 하는지” 판단할 수 있는 지표와 제안을 만든다.

## 2. 연구 질문

### 필수 질문

1. 연도별 퇴직자 수와 전체·퇴직연금 수급자 수는 어떻게 변했는가?
2. 전년 대비 증감은 어느 연령대·재직기간·학교급·직종·지역에서 주로 발생했는가?
3. 수급자 순증가는 신규 수급 개시와 수급 종료 중 어느 쪽 변화로 설명되는가?
4. 연간 퇴직자 수와 같은 해 또는 이후 신규 수급자 수는 어떤 시계열 관계를 보이는가?
5. 확보한 기간이 충분할 때 향후 수급자 규모와 신규 수급 업무량은 어떤 범위로 예상되는가?
6. 분석 결과를 공단의 업무·정책·데이터 개방에 어떻게 적용할 수 있는가?

### 데이터가 허용할 때의 확장 질문

- 공통 가명데이터의 연령·재직기간·직종·기준소득월액 구조는 향후 퇴직 압력에 어떤 시사점을 주는가?
- 추가로 연결 가능한 자료를 확보할 경우 퇴직 후 지급개시 시차는 집단별로 어떻게 다른가?
- 공개된 2022년 장기 예측치와 실제값은 얼마나 차이가 나며, 어떤 가정을 보정해야 하는가?

## 3. 분석 단위와 기본 지표

### 핵심 지표

| 지표 | 정의 | 공단 활용 |
|---|---|---|
| 연간 퇴직자 수 | 해당 연도 신규 퇴직 건수 | 퇴직급여 처리 업무량 |
| 신규 퇴직연금 수급자 | 해당 연도 처음 퇴직연금 지급을 시작한 사람 수 | 신규 수급 상담·심사·지급 업무량 |
| 연말 수급자 수 | 연말 현재 수급 중인 사람 수 | 지급·서비스 대상 규모 |
| 수급 종료자 수 | 해당 연도 수급이 종료된 사람 수 | 수급자 순증 분해 |
| 순증가 | 신규 수급자 - 수급 종료자 ± 전환·정정 | 전체 수급자 변화 설명 |
| 신규수급/퇴직 비율 | 해당 연도 신규 퇴직연금수급자 / 해당 연도 퇴직자 | 개인 전환율이 아닌 연도 단위 참고지표 |
| 구조 기여도 | 집단별 증가분 / 전체 증가분 | 우선 관리 집단 식별 |

### 주의할 정의

- 수급자 수가 연중 평균인지, 연말 시점인지 확인한다.
- 신규 수급자는 지급 승인일이 아니라 최초 지급일을 기준으로 할지 확인한다.
- 퇴직이 취소·정정되거나 재임용된 사례의 처리 규칙을 확인한다.
- 급여종류 전환을 신규 유입으로 중복 계산하지 않는다.
- 동일인이 여러 급여 이력을 가진 경우 사람 수와 지급 건수를 구분한다.

## 4. 데이터 확보 경로

### A. 공개데이터: 대기 없이 즉시 분석

1. 연도별 교직원 퇴직현황: 연도별 전체·직종·학교급·성별 퇴직자
2. 연도별 연금수급자 및 평균연금액, 1997~2025
3. 연금지급개시연령별·학교급별·직종별 수급자 현황
4. 연령별·학교급별 퇴직연금수급자 현황
5. 재직기간별·연령별 퇴직연금수급자 현황
6. 가입자·연금수급자 예측치
7. 필요하면 기준소득월액·상하한액·증감내역 집계자료

### B. 고정 이메일 신청: 공통 가명데이터

- 이메일 양식과 제공 데이터는 공통으로 정해져 있으므로 임의로 데이터명·항목을 바꾸지 않는다.
- 첨부파일 3개와 고정 양식을 그대로 제출한다.
- 실제 파일을 받은 뒤 기간·컬럼·가명키·금액 단위·보안조건을 확인한다.
- 기준소득월액 중심 자료라면 연령·지역·재직기간·소득 구조를 설명하는 보조분석에 사용한다.
- 퇴직자와 수급자의 개인 단위 전환을 직접 보여주는 자료라고 미리 가정하지 않는다.

### C. 정보공개청구: 선택 과제 보완 집계자료

정보공개청구 대상은 `2015~2025년 퇴직연금 신규 수급개시자 및 수급종료자 연도별 현황`이다.

공개데이터포털에는 연도별 퇴직자 수와 연도별 퇴직연금수급자 수가 이미 있으므로 반복 청구하지 않는다. 공개된 컬럼에 없는 다음 두 가지를 필수 요청값으로 삼는다.

1. 연도별 신규 퇴직연금 수급개시자 수
2. 연도별 퇴직연금 수급종료자 수

가능하면 이미 보유한 범위에서 교원/사무직원·학교급·수급종료 사유 구분과 급여종류 전환·정정 등 기타 증감 조정항목도 요청한다. 개인별 로우데이터, 성명, 기관명, 생년월일, 상세주소는 요청하지 않는다.

정보공개청구는 공공기관이 보유·관리하는 기존 정보의 공개를 요구하는 제도다. 새 분석이나 의견 작성을 요구하지 않고, 기존 통계표 또는 전자자료를 요청한다. 일부 항목을 공개하기 어렵다면 나머지 항목의 부분공개와 더 큰 범주의 집계자료 제공을 요청한다.

## 5. 신청 절차와 복사용 청구문

### 이메일 가명데이터 신청

공단이 안내한 고정 이메일 양식과 첨부파일 3개를 그대로 제출한다. 이 문서에서는 이메일 내용을 수정하지 않는다.

### 정보공개청구

청구기관은 `사립학교교직원연금공단`, 공개방법은 `전자파일`, 수령방법은 `정보공개포털을 통한 온라인 수령`을 우선 선택한다. 실제 포털의 선택지 명칭이 다르면 같은 의미의 항목을 고른다.

붙여넣을 제목과 본문은 `docs/03_정보공개청구_복사용.md`에 별도로 정리했다.

공식 안내상 기관은 접수 후 소관부서로 이관해 공개·부분공개·비공개·정보부존재 여부를 결정하며, 공개 여부 결정은 원칙적으로 접수일부터 10일 이내다. 부득이한 경우 10일 범위에서 연장될 수 있다.

## 6. 분석 방법

### 1단계: 데이터 품질검사

- 기간·단위·기준일·중복·결측 확인
- 공개데이터·공통 가명데이터·정보공개자료의 총계와 범위 대조
- 희소 셀과 범주 변경 여부 확인
- 수급자 저량 변화가 `신규-종료±조정`과 맞는지 검증
- 사람 수와 지급 건수, 연말 기준과 연중 누계가 섞이지 않았는지 검사

### 2단계: 기초 추이

- 연도별 퇴직자, 신규 수급자, 연말 수급자, 종료자
- 전년 대비 증감률, 증가분, 기준연도 지수, 장기 연평균 증가율
- 연금 종류별 수급자와 평균연금액 추이

### 3단계: 구조 분해

- 연령대·학교급·직종·재직기간·지역별 구성비
- 전체 증가분에 대한 집단별 기여도
- 정년·조기·기타 퇴직 유형 비교, 제공 시

### 4단계: 퇴직 흐름과 수급자 증감의 연도 단위 연결

- `전년 말 수급자 + 신규 수급자 - 수급 종료자 ± 조정 = 금년 말 수급자` 점검
- 연도별 퇴직자 수와 같은 해·1년 후·2년 후 신규 수급자 수의 움직임 비교
- 교원/사무직원·학교급별 자료가 있으면 전체 증감 기여도 비교
- 개인을 연결한 자료가 아니므로 개인별 전환율·지급개시 시차·인과효과로 해석하지 않음

### 5단계: 예측

- 연간 관측치가 20~30개 수준이면 복잡한 딥러닝보다 단순 기준모형, 지수평활, ARIMA 등 작은 표본에 적합한 모형을 비교한다.
- 롤링 시계열 검증으로 1~3년 앞 예측오차를 비교한다.
- 점 하나가 아니라 기준·증가·감소 시나리오 범위를 제시한다.
- 2022년 공개 예측치와 실제값을 비교해 기존 전망의 편차를 확인한다.

### 6단계: 공단 행동안

분석 결과별로 다음 템플릿을 쓴다.

| 문제 | 데이터 근거 | 가능한 해석 | 제안 행동 | KPI |
|---|---|---|---|---|
| 예: 특정 연도 이후 신규 수급 집중 | 퇴직자 증가 뒤 신규 수급자 증가가 반복됨 | 정년 도달·지급개시연령 효과 가능 | 사전 안내·상담·심사 인력 배치 검토 | 처리기간, 문의량, 사전신청률 |

## 7. 공단에 실질적으로 도움이 되는 결과 예시

실제 데이터로 검증되기 전에는 아래를 결론이 아니라 **검증할 활용 가설**로 취급한다.

1. `퇴직자 발생→신규수급 유입→수급 종료`를 연 단위로 모니터링해 상담·심사·지급 업무량을 미리 준비한다.
2. 연령대·학교급·직종·재직기간별로 수급 유입 압력이 큰 집단을 찾아 맞춤형 사전 안내를 한다.
3. 수급자 순증가를 신규 유입과 종료 감소로 분리해 재정·서비스 수요의 원인을 설명한다.
4. 예측치와 실제값의 차이를 매년 검증하는 조기경보 지표를 만든다.
5. 단면 집계 위주의 공개데이터를 연도 컬럼이 포함된 장기 시계열·전환 집계 데이터로 개선한다.
6. 보고서에서 확인된 데이터 정의·코드·희소 셀 문제를 데이터 품질 개선 목록으로 환류한다.

## 8. 3인 팀 역할안

| 역할 | 1차 책임 | 교차 검토 |
|---|---|---|
| A. 데이터·재현 담당 | 파일 수집, 정제, 데이터 사전, 품질검사, 분석 코드 | 정책 담당이 지표 의미 검토 |
| B. 분석·시각화 담당 | 추이, 구조 분해, 전환·예측, 그래프 | 데이터 담당이 계산 재검산 |
| C. 정책·커뮤니케이션 담당 | 공단 활용안, 보고서, PPT, 일정·질의 관리 | 분석 담당이 표현의 근거 검토 |

모든 그래프와 핵심 수치는 작성자 외 1명이 재검산한다. 발표는 세 명이 `문제·목적 / 분석 결과 / 공단 제안`으로 나눌 수 있다.

## 9. 일정안

가명데이터 제공이 3~10영업일 걸린다는 공단 안내를 전제로 한다.

### 신청일~자료 도착 전

- 고정 이메일 양식과 첨부 3개 제출
- 정보공개포털에 비식별 연도별 집계자료 청구
- 공개데이터 수집·정의 확인·기초 분석
- 보고서와 PPT 목차 확정
- 가명데이터 품질검사 코드 준비

### 각 자료 도착 후 1~2일

- 보안조건 확인
- 데이터 사전 작성
- 중복·결측·범주·기간·총계 검증
- 정보공개 결정과 제공 누락 항목 확인

### 그 다음 2주

- 추이·구조·연도 단위 증감 연결 분석
- 공개데이터·가명데이터·정보공개자료 결과 교차검증
- 핵심 그래프 8~12개 확정

### 다음 1주

- 공단 행동안과 데이터 개방 개선안 작성
- 보고서 1차본과 PPT 스토리라인 작성

### 마지막 1주

- 지도교수 검토 반영
- 수치 재검산·한계 명시·발표 리허설
- 공개 가능한 결과와 내부 가명데이터 결과 분리

## 12. 분석의 레드라인

- 단면 데이터로 장기 추이를 주장하지 않는다.
- 집계자료의 선후 움직임만으로 `퇴직자 증가 때문에 수급자가 증가했다`고 인과를 단정하지 않는다.
- 개인 연결자료가 없으면 `전환율`, `개인별 지급개시 시차`라는 표현을 쓰지 않는다.
- 연금수급자와 퇴직연금수급자를 혼용하지 않는다.
- 수급자 사람 수와 급여 지급 건수를 혼용하지 않는다.
- 작은 집단을 식별할 수 있는 표·그래프를 외부 산출물에 넣지 않는다.
- 예측 결과를 확정 미래처럼 표현하지 않는다.
- 화려한 대시보드가 보고서의 정의·품질검사·행동 제안보다 앞서지 않게 한다.
