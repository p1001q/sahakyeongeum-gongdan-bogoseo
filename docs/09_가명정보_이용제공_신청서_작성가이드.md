- 작성일: 2026-08-27
- 대상 데이터: `사립학교교직원연금공단_기준소득월액`
- 신청 대표: 서경대학교 상상이상팀 박수연

## 장수 판단

- 현재 확인된 사진은 `가명정보 이용·제공 신청서` 1장뿐이다.
- 기준소득월액 가명데이터 1건에 대해서는 이 신청서 1장을 작성하는 것으로 본다.
- 이메일에서 추가 요청하는 연도별 신규 수급개시자·수급종료자 **집계표**는 가명정보가 아니므로 같은 신청서를 한 장 더 작성하지 않는다.
- 공단이 해당 추가자료를 개인 단위 가명 로우데이터로 제공할 수 있다고 답하고 별도 신청서를 요구할 때만 두 번째 신청서를 작성한다.
- 강석 담당자가 말한 `첨부파일 3개`는 서로 다른 신청·서약 양식일 수 있다. 나머지 양식을 확인하기 전에는 전체 제출 장수를 확정할 수 없다.

## 사진 속 현재 기재사항 중 수정할 것

- `담당자 성명`의 강석은 지우고 실제 신청자인 `박수연`으로 작성한다.
- `접수번호`와 `접수일`은 공단 접수 담당자 기재란으로 보이므로 비워 둔다. 담당자가 신청자에게 날짜 기재를 지시한 경우에만 작성한다.
- 이미 볼펜으로 잘못 적었다면 수정테이프보다 새 용지에 다시 작성하는 것을 권장한다.

- 가명데이터 원본은 팀원 3명 외에 공유하지 않는다.
- 공개 GitHub·Notion·클라우드 공유링크에 원본 CSV를 올리지 않는다.
- 분석 결과에는 개인 행을 싣지 않고 집계표와 그래프만 사용한다.
- 소수 인원 셀은 합치거나 표시하지 않는다.
- 프로젝트 종료 또는 공단이 정한 이용기간 종료 후 원본·중간파일 처리 지침을 확인한다.
