- 작성일: 2026-08-31

- 범위: 본문을 작성하지 않고, 보고서의 목차·장별 역할·논리·증거·시각자료를 확정한다.

## 1. 제목 확정안

### 권장 제목

**퇴직자·수급자 변화 분석을 통한 사학연금 디지털 고객서비스 공공데이터 고도화 방안**

### 부제

**공단 공개데이터 186개 전수검토와 신규 개방 설계를 중심으로**

### 제목 판단

- `퇴직자·수급자 변화 분석`을 제목 앞에 두어 공단이 제시한 선택 과제와의 정합성을 보여준다.
- `디지털 고객서비스`는 강석 담당자가 제시한 고령 수급자의 접속·인증 연구 방향을 반영한다.
- `공공데이터 고도화`는 신규 개방만이 아니라 기존 데이터의 품질·정의·연결성 개선을 포함한다.
- `186개 전수검토`를 부제에 넣어 단순 AI 제안서가 아니라 공식 공개자료를 실제로 점검한 결과임을 명확히 한다.

## 2. 한 문장 주장

> 사학연금 공개데이터는 퇴직자·수급자의 장기 변화와 일부 상담·온라인 접수 현황을 파악하는 데에는 유용하지만, 수치 정의·기준일·연결 변수의 불일치로 인해 연령대별 디지털 이용 편의성과 채널 전환을 직접 측정하기 어렵다. 따라서 기존 데이터의 품질 개선과 `연령대×채널×인증×업무완료` 통계의 단계적 개방을 병행해야 한다.

## 3. 보고서 전체 사고 흐름

### 잘못된 흐름

`수급자가 증가했다 → 연구하려 했지만 데이터가 없어 못했다 → 데이터를 내놓아라`

이 흐름은 보고서를 미완성 연구로 보이게 하고, 이미 공개된 상담·VOC·인터넷 접수 데이터를 무시하는 결과가 된다.

### 확정 흐름

1. **과제 정의**: 퇴직자·수급자 변화가 공단 업무와 고객서비스에 무엇을 요구하는지 묻는다.
2. **전수 확인**: 공단 공개데이터 186개를 전수 목록화하고 현재 연구와 관련된 후보를 선별한다.
3. **기존 데이터 활용**: 퇴직자·퇴직연금수급자·평균연금액의 장기 변화를 분석한다.
4. **서비스 자료 활용**: 상담 채널·VOC·인터넷 접수·홈페이지 가입자 통계로 현재 공개 범위에서 알 수 있는 것을 먼저 분석한다.
5. **분석 공백 확인**: 연령·수급자 여부·PC/모바일·인증·업무완료·상담 전환이 같은 집계에서 연결되지 않아 디지털 편의성 가설을 검증할 수 없음을 보인다.
6. **품질 한계 확인**: 수급자 공표값, 상담 합계, 연월 표기, 컬럼 정의 불일치를 실제 사례로 제시한다.
7. **고도화 설계**: `기존 파일 품질개선`과 `신규 연결 통계 개방`을 두 축으로 설계한다.
8. **공단 활용 설계**: 서비스 개선, 상담 운영, 데이터 품질관리, 외부 연구에 어떻게 쓸지를 시나리오와 KPI로 제시한다.
9. **선순환 완성**: `데이터 개방 → 연구 활용 → 서비스·품질 개선 → 보완·재개방`으로 공단 추진계획의 목표에 연결한다.

## 6. 장별 설계서

### 요약문

- **역할**: 심사자가 본문을 읽지 않아도 문제·분석·제안·기대효과를 파악하게 한다.
- **구성**: 배경 15%, 방법 15%, 핵심 발견 30%, 제안 25%, 실행·기대효과 15%.
- **필수 요소**: 검증된 핵심 수치 3~5개, 품질 발견 2~3개, 2축 고도화안, 3단계 로드맵.
- **금지**: 결과를 과장하거나 “데이터가 없어 실패했다”고 표현하지 않는다.

### Ⅰ. 연구 개요

- **역할**: 공단의 선택 과제와 연구가 어떻게 연결되는지 설명한다.
- **핵심 질문**:
  1. 퇴직자와 퇴직연금수급자는 어떻게 변했는가?
  2. 현재 공개된 서비스 데이터로 무엇을 알 수 있는가?
  3. 디지털 이용 편의성과 채널 전환을 판단하려면 무엇이 더 필요한가?
  4. 공단은 어떤 순서로 데이터를 개선·개방하고 성과를 측정할 것인가?
- **시각자료**: 연구 전체 흐름도 1개.

### Ⅱ. 공공데이터 활용 및 검증방법

- **역할**: “AI가 생성한 제안”이 아니라 공식 데이터 활용 연구임을 증명한다.
- **핵심 증거**: 193건 검색→제공기관 일치 186건, 8개 주제군, 관련 후보, 원본 보존, 해시, 재현 코드.
- **시각자료**:
  1. 186개 데이터 주제별 분포.
  2. 데이터 선정·검증 흐름도.
  3. 핵심 데이터 소스 맵.
- **주의**: 15개 파일의 값 검사를 186개 전체의 값 검사로 과장하지 않는다.

### Ⅲ. 퇴직자·수급자 변화 분석

- **역할**: 공단 선택 과제에 직접 답하고, 디지털 서비스 개선의 수요 배경을 만든다.
- **사고 순서**: 현상→규모→변화 속도→구조→업무적 의미.
- **핵심 시각자료**:
  1. 전체·교원·사무직원 퇴직자 추이.
  2. 퇴직연금수급자 장기 추이.
  3. 수급자 순증·증감률.
  4. 퇴직연금 평균연금액.
  5. 연령 구조 분포.
- **핵심 주의**: 퇴직자는 유량, 수급자는 저량이며, 수급자 순증을 신규 수급개시자로 표현하지 않는다.

### Ⅳ. 현행 디지털 고객서비스 공개데이터 분석

- **역할**: “디지털 데이터가 전혀 없다”는 잘못된 주장을 피하고, 이미 공개된 자료의 활용 가치를 보여준다.
- **사고 순서**: 이미 알 수 있는 것→지표의 의미→단독 해석의 한계→연결 필요성.
- **핵심 시각자료**:
  1. 상담 채널별 구성과 변화.
  2. VOC 업무유형별 규모·변화.
  3. 인터넷 접수 유형별 변화.
  4. 현재 자료로 가능한 분석과 불가능한 분석의 대조표.
- **핵심 주의**: 전화 비중이 높다는 사실을 고령층의 디지털 불편 원인으로 단정하지 않는다.

### Ⅴ. 분석 공백 및 공공데이터 품질진단

- **역할**: 분석이 무엇 때문에 막히는지를 구체적 사례와 수치로 입증한다.
- **두 가지 한계를 분리**:
  1. `분석 공백`: 필요한 변수가 없거나 서로 연결되지 않음.
  2. `데이터 품질`: 이미 공개된 값·합계·날짜·컬럼 정의가 일관되지 않음.
- **필수 사례**:
  1. 2025년 퇴직연금수급자 공표값 차이.
  2. 2023~2025년 상담 채널 합계 불일치.
  3. 인터넷 접수·홈페이지 가입자의 연월 표기 문제.
  4. 75세 기준 지역 파일의 컬럼 오표기.
  5. 2020년 8월 기준 1회성 수급종료자 통계.
- **표현 원칙**: 비판이 아니라 `확인된 사례 → 분석 영향 → 수정 제안 → 품질 KPI`로 쓴다.

### Ⅵ. 디지털 고객서비스 공공데이터 고도화 방안

- **역할**: 한계를 실행 가능한 데이터 설계로 변환한다.
- **1축: 기존 데이터 품질 개선**:
  1. 기준일·모집단·포함범위·산식 명시.
  2. 총계와 부문 자동검증.
  3. 연월 표현방식 표준화.
  4. 컬럼명·단위·자료형 정정.
  5. 수정이력·현행화 주기 제공.
- **2축: 신규 연결 통계 개방**:
  1. 기준연월.
  2. 이용자구분(재직자·수급자·기타).
  3. 연령대.
  4. 접속채널(PC웹·모바일웹·앱).
  5. 서비스유형.
  6. 인증방법.
  7. 인증시도·성공·실패.
  8. 실패사유 범주.
  9. 업무완료·중도이탈.
  10. 비밀번호 재설정·인증 알림톡.
  11. 디지털 이용 후 상담 전환.
- **강석 담당자 4개 항목**: PC/모바일, 인증방법, 인증실패, 비밀번호 분실 알림톡을 누락 없이 명시한다.
- **추가 항목**: 서비스유형, 업무완료, 중도이탈, 실패사유, 상담 전환, 반복상담, 수정이력.
- **시각자료**:
  1. 현재 데이터→제안 데이터 연결 모형.
  2. 제안 데이터 정의서 요약표.
  3. 단계별 개방 우선순위.

### Ⅶ. 공단 활용방안·실행 로드맵·성과지표

- **역할**: “데이터를 공개하면 좋다”에서 끝나지 않고 공단의 실제 행동으로 전환한다.
- **활용 시나리오**:
  1. 연령대·인증방법별 실패율을 활용한 인증 안내 개선.
  2. 서비스유형·중도이탈 단계별 화면·절차 개선.
  3. 디지털→전화 전환율을 활용한 상담 인력·안내 우선순위 조정.
  4. 미청구자 안내→청구 전환을 활용한 미수령 급여 예방.
  5. 외부 연구자의 디지털 포용·민원예측·UX 연구.
- **로드맵**:
  1. 1단계: 기존 파일 정의·합계·날짜 정정.
  2. 2단계: 강석 담당자 제안 4개 핵심 통계 시범 개방.
  3. 3단계: 서비스유형·완료·상담 전환 연결.
  4. 4단계: 정기 공개·외부 활용·품질 개선 환류.
- **서비스 KPI**: 인증성공률, 업무완료율, 중도이탈률, 상담전환율, 반복상담률, 비밀번호 재설정률.
- **데이터 KPI**: 합계일치율, 필수 메타데이터 충족률, 갱신준수율, 오류수정 소요일, 후속 활용사례 수.
- **평가 연결**: 활용실적, 혁신사례, 국민체감, 신규 개방, 품질개선, 재개방의 증거를 종합한다.

### Ⅷ. 결론

- **역할**: 새로운 주장을 추가하지 않고, 앞의 근거와 제안을 공단의 즉시 검토사항으로 압축한다.
- **결론 순서**: 핵심 발견 3개→즉시 개선 3개→중기 개방 3개→한계→후속 과제.
- **종결 문장의 개념**: 공단은 이미 다양한 통계를 개방하고 있으며, 이제는 파일 수의 확대를 넘어 연결 가능성·정의 일관성·활용 성과를 관리하는 단계로 발전할 필요가 있다.
