# 보고서 장별 패키지 제작 인수인계

- 작성일: 2026-08-31
- 목적: 긴 대화 기록 없이도 새 세션이 현재 확정사항·검증 결과·남은 작업을 정확히 이어가게 한다.
- 현재 단계: 보고서 구조 확정 및 데이터·그래프 검증 완료 → **Ⅲ장부터 장별 제작 패키지 작성**
- 최종 문서 제작: 별도의 전문 보고서 제작 AI가 수행한다. Codex는 사용자 재지시 전까지 DOCX·PDF·PPT를 만들지 않는다.

## 1. 지금부터의 단일 목표

공식 공개데이터와 재현 가능한 계산만 사용해 전문 보고서 제작 AI가 그대로 이해하고 조판할 수 있는 **장별 구조·본문·시각자료·출처·검증 패키지**를 완성한다.

여기서 패키지는 개요나 아이디어 목록이 아니다. 각 장의 제목·소제목별로 실제 본문에 들어갈 문장, 근거 수치, 표·그래프 삽입 위치, 캡션, 출처, 해석 한계, 다음 장과의 연결까지 완성된 전달본을 뜻한다.

## 2. 확정사항

### 2.1 제목과 핵심 주장

**제목**  
퇴직자·수급자 변화 분석을 통한 사학연금 디지털 고객서비스 공공데이터 고도화 방안

**부제**  
공단 공개데이터 186개 전수검토와 신규 개방 설계를 중심으로

**한 문장 주장**  
사학연금 공개데이터는 퇴직자·수급자의 장기 변화와 일부 상담·온라인 접수 현황을 파악하는 데 유용하지만, 수치 정의·기준일·연결 변수의 불일치로 연령대별 디지털 이용 편의성과 채널 전환을 직접 측정하기 어렵다. 따라서 기존 데이터의 품질 개선과 `연령대×채널×인증×업무완료` 통계의 단계적 개방을 병행해야 한다.

### 2.2 최종 목차와 작성 순서

최종 목차는 다음 8개 장으로 고정한다.

1. Ⅰ. 연구 개요
2. Ⅱ. 공공데이터 활용 및 검증방법
3. Ⅲ. 퇴직자·수급자 변화 분석
4. Ⅳ. 현행 디지털 고객서비스 공개데이터 분석
5. Ⅴ. 분석 공백 및 공공데이터 품질진단
6. Ⅵ. 디지털 고객서비스 공공데이터 고도화 방안
7. Ⅶ. 공단 활용방안·실행 로드맵·성과지표
8. Ⅷ. 결론

실제 작성은 **Ⅲ → Ⅳ → Ⅴ → Ⅵ → Ⅶ → Ⅰ → Ⅱ → Ⅷ → 요약문** 순서로 한다. 구조를 다시 브레인스토밍하지 않는다.

### 2.3 담당자 제안과 추가 설계

강석 담당자가 제안한 아래 4개 요소는 모두 Ⅵ장의 신규 데이터 설계에 반영한다.

1. 연령대별 PC·모바일 접속
2. 연령대별 인증방법
3. 연령대별 인증성공·실패와 실패사유
4. 연령대별 비밀번호 분실 인증 알림톡 발송

추가 요소는 서비스 업무유형, 업무완료·중도이탈, 상담 전환, 반복 문의, 데이터 기준일·정정이력이다. 개인식별값은 제외하고 연령대 범주화·소수 셀 억제를 적용한다.

## 5. 절대 혼용하면 안 되는 공식 수치

공식 자료라도 공표 단위·기준일·모집단이 다르면 값이 달라진다. 아래 값은 하나의 총계로 합치거나 임의로 교체하지 않는다.

| 자료 | 값 | 사용 원칙 |
|---|---:|---|
| 공공데이터포털 15045820 `연도별 연금수급자 및 연금액` | 2025년 퇴직연금수급자 111,389명 | 1997~2025 장기 추이 그래프에만 사용 |
| 공공데이터포털 15064966 `연금수급자 및 연금선택률` | 2025년 114,079명 | 해당 파일의 정의·기준 안에서만 사용 |
| 공공데이터포털 15045815 연령×학교급 부문 합 | 114,079명 | 해당 단면의 범위와 기준을 명시 |
| 공공데이터포털 15045816 연령×재직기간 부문 합 | 118,656명 | 정의·기준일 확인 전 장기 추이 총계로 사용 금지 |
| 공공데이터포털 15045812 평균연금월액 파일 수급자 합 | 118,656명 | 연령 분포 보조 및 품질 사례에만 조건부 사용 |

이 차이는 곧바로 `오류`라고 단정하지 않는다. 공표 기준 차이일 수 있으나 이용자가 차이를 해석할 기준일·모집단·집계 정의가 충분하지 않다는 **정합성·설명성 개선 사례**로 다룬다.

추가로 2025년 교원 퇴직자는 장기 연도별 파일에서 14,789명, 학교급·지역·퇴직사유 파일 내부 합계에서 14,193명으로 596명 차이가 난다. 07번 그래프는 반드시 `학교급·지역·퇴직사유 파일에 수록된 14,193명 기준`이라고 쓴다.

## 6. 현재 사용할 수 있는 핵심 사실

아래 값은 원본과 재현 코드로 검증됐지만, 장별 패키지 작성 시 다시 근거 파일과 산식을 연결한다.

- 2025년 전체 퇴직자: 27,495명(교원 14,789명, 사무직원 12,706명)
- 2024년 전체 퇴직자: 37,305명, 2025년 전년 대비 26.30% 감소
- 퇴직연금수급자: 1997년 4,997명 → 2025년 111,389명, 22.29배
- 2025년 퇴직연금수급자 순증: 5,623명, 전년 대비 5.32%
- 퇴직연금 평균연금액: 1997년 1,365,170원 → 2025년 3,318,230원, 명목 143.06% 증가
- 공단 홈페이지 가입자 100명당 전체 연금수급자: 2021년 29.9명 → 2025년 39.4명
- 2025년 교원 퇴직사유 파일 내부 합계: 14,193명. 의원일반 8,754명, 정년 4,050명, 명예 1,232명 등
- 15045812의 경계값을 `n미만`이라는 문언대로 상한 미만 구간으로 분류하면 60세 이상이 96.7%다. 다만 총계 118,656명의 공표 범위와 구간 규칙을 캡션에 명시한다.

평균연금액 장기 추이는 명목금액이며 실질 구매력 증가로 쓰지 않는다. 15045812의 연령별 평균연금월액은 원값 최대 49,820,709원과 메타데이터가 충돌하므로 공단 확인 전 실제 연금수준 분석에 사용하지 않고 Ⅴ장의 단위·값 정의 품질 사례로만 쓴다.

## 7. 장별 패키지의 필수 구성

각 장의 파일은 아래 9개 블록을 모두 포함한다.

1. **장 역할과 핵심 결론**: 이 장이 보고서 전체에서 증명할 한 문장
2. **앞뒤 장 연결**: 앞 장에서 무엇을 받고 다음 장으로 무엇을 넘기는지
3. **세부 목차와 논증 지도**: 제목·소제목·문단별 `문제 → 근거 → 해석 → 제안 → KPI`
4. **본문 원고**: 전문 AI가 요약 없이 사용할 수 있는 제목 단위 문장과 단락
5. **팩트시트**: 수치, 단위, 기준기간, 모집단, 산식, 원자료명, URL, 로컬 파일, 주의사항
6. **시각자료 삽입표**: 파일명, 삽입 위치, 캡션, 독자가 읽어야 할 한 문장, 출처 표기, 대체텍스트
7. **사실·해석·가설·제안 구분**: 문장별 성격이 뒤섞이지 않도록 명시
8. **허용 주장과 금지 주장**: 데이터가 지지하는 범위와 넘으면 안 되는 해석
9. **자체 검수표**: 원본 대조, 합계, 단위, 링크, 그림 수치, 중복, 다음 장 연결 확인

패키지의 수치마다 `어떤 파일의 어떤 열을 어떤 방식으로 계산했는지`가 추적돼야 한다. 출처 표기는 기관명·정확한 데이터명·기준일 또는 수정일·URL을 포함한다.

## 9. 바로 다음 작업: Ⅲ장 패키지

- 현재 자료로 `고령자는 디지털 이용이 어렵다`, `인증에 실패한다`고 단정하지 않는다.
- 퇴직자 수, 퇴직연금수급자 수, 전체 연금수급자 수를 같은 지표처럼 연결하지 않는다.
- 수급자 순증을 신규 수급자 수라고 쓰지 않는다.
- 상관관계·동반 추세를 원인 또는 정책 효과로 표현하지 않는다.
- 186개 전부의 원본값을 검증했다고 쓰지 않는다.
- 보류·제외된 팀원 그래프를 본문에 삽입하지 않는다.
- 보고서 패키지가 완성되기 전에 DOCX·PDF·PPT·앱·대시보드를 만들지 않는다.

## 11. 완료 판정

장별 패키지가 완료됐다는 말은 다음을 모두 만족할 때만 쓴다.

- 모든 핵심 수치가 원본·코드·출처 URL로 역추적된다.
- 그래프의 값·축·단위·기간·모집단·캡션이 원자료와 일치한다.
- 공식 공표값 차이를 숨기거나 임의로 통합하지 않았다.
- 사실·해석·가설·제안이 구분돼 있다.
- 본문이 제목 단위로 충분히 작성돼 전문 AI가 내용을 새로 발명할 필요가 없다.
- 공단의 행동과 KPI로 연결된다.
- `python3 scripts/verify_workspace.py`가 정상 판정을 낸다.
